# ER-Model: Online Food Delivery System (Концептуальна модель даних)

## 1. Опис предметної області (Domain)
Цей проєкт реалізує концептуальну модель даних для платформи онлайн-замовлення та доставки їжі. Система забезпечує взаємодію між трьома основними суб'єктами:
- **Клієнти** (здійснюють вибір страв та оформлюють замовлення).
- **Ресторани / Заклади** (керують меню, категоріями страв та обробляють замовлення).
- **Кур'єри** (виконують доставку замовлень за вказаними адресами).

## 2. Мета роботи
Побудова нормалізованої ER-моделі (до рівня 3NF) з використанням декларативного синтаксису (Mermaid), детальна специфікація сутностей, атрибутів, первинних/зовнішніх ключів та кардинальностей зв'язків без дублювання та зайвих сполучних таблиць (проміжних сутностей без власних атрибутів).
